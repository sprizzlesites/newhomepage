Why it looks hand-drawn

The letters bounce themselves

Every letter has three cut versions — upright, tilted up, tilted down — and the font's calt feature cycles through them as you type. The drips are the same idea: each letter carries a second cut with tapered drips hung off its real bottom edge, switched on by ss01. No spans, no script, no markup.

Mode 1 · recommended

Full look

Two fonts stacked: the cyan edge as filled shapes underneath, the glossy body on top. Colours stay editable in CSS. The text is duplicated into data-text so the second layer has something to draw.

Full look
<link rel="stylesheet" href="sprizzle.css">

<h1 class="sprizzle" data-text="Sprizzle!">Sprizzle!</h1>

Don't want to write everything twice? One line fills data-text for you:

<script>
  document.querySelectorAll(".sprizzle").forEach(function (el) {
    el.dataset.text = el.textContent;
  });
</script>

Mode 3

Baked colour

All six layers live inside SprizzleColor-Regular.woff2 as a COLR/CPAL colour font. Nothing to duplicate and nothing to stroke — but the palette is fixed, and browsers without colour-font support fall back to flat pink.

Change the colours

Modes 1 and 2 read eight custom properties. Override them globally or on a single element.

Slime
Creamsicle
.hero-title {
  --sprizzle-fill: #ffd400;
  --sprizzle-fill-top: #fdffb0;      /* gloss    */
  --sprizzle-fill-bottom: #d18f00;   /* shade    */
  --sprizzle-shadow: #1b3b00;        /* contour  */
  --sprizzle-edge: #7bff2e;          /* edge     */
  --sprizzle-edge-w: 0.16em;         /* thicker  */
}
